## GoodGrit ##

Final Year Project - April/September 2024

A mobile app for working out, designed to help users stay fit and achieve their fitness goals efficiently.

### Features

- Track workouts and monitor progress.
- Apple Health integration for accurate data syncing.
- Firebase backend for secure data management.
- Payment handling with Stripe API mocking.

### Built With

- [Flutter](https://flutter.dev/) for cross-platform mobile development.
- [Apple Health](https://developer.apple.com/documentation/healthkit/) for iOS fitness tracking integration.
- [Firebase](https://firebase.google.com/) for backend services.
- [Stripe](https://stripe.com/) as a mock API for payment handling.
